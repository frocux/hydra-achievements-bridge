# Ручные привязки «папка игры = номер игры в Steam».
#
# Скопируй этот файл в games.txt и добавляй строки по мере надобности.
#
# Нужны там, где у игры в steam_appid.txt написана ерунда вместо числа
# (тогда эмулятор сваливает достижения в папку «0») или где номер вообще
# нигде не записан.
#
# Слева пишем имя папки игры. Сравнение идёт без учёта регистра и пробелов,
# поэтому «My Game» и «mygame» — одно и то же.
# Номер можно подсмотреть на странице игры в Steam: в адресе .../app/1234567/

# Например:
# My Game = 1234567
# Another Game Deluxe Edition = 7654321
